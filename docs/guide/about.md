# 关于本站

这是一个用来记录**工作中和学习中遇到的问题**的个人博客。

## 为什么建这个站

- 排查过的问题，过两个月再遇到往往忘得七七八八，写下来方便回溯
- 把踩坑过程整理成文章，本身就是一次深度复习
- 如果恰好帮到了搜索进来的你，那就是额外赚到的 😄

## 内容范围

| 分类 | 收录内容 |
| --- | --- |
| 前端 | 页面渲染、打包构建、浏览器兼容、组件库踩坑 |
| 后端 | 接口异常、框架配置、并发与性能问题 |
| 数据库 | SQL 优化、索引失效、锁与事务问题 |
| 工具链 | Git、Docker、CI/CD、编辑器与命令行工具 |

## 写作格式约定

每篇文章的 Front Matter 统一为：

```yaml
---
title: 文章标题
date: 2026-01-01
tags: [标签1, 标签2]
---
```

正文推荐按 **问题现象 → 排查过程 → 根因 → 解决方案 → 举一反三** 的结构来写。
